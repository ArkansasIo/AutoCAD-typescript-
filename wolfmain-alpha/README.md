# WolfMain Alpha — TypeCAD adapter

This directory documents the integration boundary for the WolfMain Alpha math library. The upstream source repository/API was not supplied, so TypeCAD does not claim this shim is the original library. See `src/math/WolfMainAlphaAdapter.ts` and `docs/WOLFMAIN_ALPHA.md`.

Planned domains: vectors/matrices, coordinate transforms, robust intersections, curves, units, numerical tolerances, parametric constraints, 3D transforms and spatial-index helpers.
