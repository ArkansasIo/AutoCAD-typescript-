# UML diagram index

- `uml/architecture.mmd`: editor, document, renderer, command, scripting and API boundaries.
- `uml/database.mmd`: users, projects, drawings, layers, entities and revisions.
- `uml/use-cases.mmd`: designer and administrator workflows.
- `uml/workplanes.mmd`: nested workplane hierarchy and coordinate operations.
